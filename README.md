# 로봇 매니퓰레이션 연구 위키

VLA, 로봇 파운데이션 모델·월드모델, 궤적 최적화, 모델예측제어, 그리고 이들이 공통으로 딛고 선 생성 모델 기초까지
다섯 계열의 문헌을 계보 중심으로 정리한 위키입니다.
2023년 6월부터 2026년 8월까지의 문헌 82편과 미해결 영역 12개를 수록했습니다.

## 구성

본문 「로봇 매니퓰레이션 연구」가 최상위 문서이고, 개요와 용어부터 계열별 동향, 데이터셋과 평가,
계열 간 관계까지를 다룹니다. 표제어를 누르면 해당 논문 문서로 이동합니다.

논문 문서는 82편이며, 각각 인포박스(계열·주체·시점·식별자·게재처·원문 링크)와 요약,
그리고 문제 → 핵심 아이디어 → 방법 → 결과 → 한계 순의 본문을 갖습니다.
보조 문서로는 계열 문서 6편, 연표, 미해결 문제, 전체 논문 목록이 있습니다.

딥링크가 동작하므로 개별 문서를 바로 열 수 있습니다.

- 논문 문서: `#/paper/<slug>` — 예: [`#/paper/dreamzero`](https://piggene.github.io/robot-manipulation-wiki/#/paper/dreamzero)
- 계열 문서: `#/track/<key>` — `vla`, `rfm`, `traj`, `mpc`, `data`, `gen`
- 그 외: `#/list`, `#/timeline`, `#/open-problems`

## 작성 규칙

1. 성능 수치와 주장은 원 논문 또는 공식 릴리스가 보고한 값을 옮겼습니다. 평가 프로토콜이 다른 논문의 수치는 직접 비교하지 않았습니다.
2. 미해결 판정의 근거는 세 유형으로 구분했습니다. 벤치마크 실측, 논문 자신의 한계 진술, 정리자 종합. 세 번째 유형은 해당 문단에 명시했습니다.
3. 초록과 공개 정보만으로 작성한 문서 35편은 상단에 그 사실을 표시하고 분류에 `초록 기반 문서`를 붙였습니다.
4. 산업계 릴리스(Gemini Robotics, GR00T)의 성능 주장은 논문이 아니라 블로그·보도자료 기반이며 독립 재현이 없다는 점을 각 문서에 표기했습니다.
5. 2026년 arXiv 식별자는 YYMM 규칙을 따릅니다. 2601은 2026년 1월입니다.

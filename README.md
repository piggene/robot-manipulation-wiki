# 로봇 매니퓰레이션 연구 위키

VLA, 로봇 파운데이션 모델·월드모델, 궤적 최적화, 모델예측제어 네 계열의 문헌을 계보 중심으로 정리한 위키입니다.
2023년 6월부터 2026년 8월까지의 문헌 76편과 미해결 영역 12개를 수록했습니다.

**사이트:** https://piggene.github.io/robot-manipulation-wiki/

## 구성

- 본문 「로봇 매니퓰레이션 연구」 — 개요, 배경과 용어, 계열별 동향, 데이터셋과 평가, 계열 간 관계
- 논문 문서 76편 — 인포박스, 요약, 주요 논문은 개요·방법·보고된 결과·한계로 구분
- 계열 문서 5편, 연표, 미해결 문제, 전체 논문 목록

## 작성 규칙

1. 성능 수치와 주장은 원 논문 또는 공식 릴리스가 보고한 값을 옮겼습니다. 평가 프로토콜이 다른 논문의 수치는 직접 비교하지 않았습니다.
2. 미해결 판정의 근거는 세 유형으로 구분했습니다. 벤치마크 실측, 논문 자신의 한계 진술, 정리자 종합. 세 번째 유형은 해당 문단에 명시되어 있습니다.
3. 산업계 릴리스(Gemini Robotics, GR00T)의 성능 주장은 논문이 아니라 블로그·보도자료 기반이며 독립 재현이 없다는 점을 각 문서에 표기했습니다.
4. 2026년 arXiv 식별자는 YYMM 규칙을 따릅니다. 2601은 2026년 1월입니다.
